# User Testing
Joining the testers on Google Play is a two step process.  First you must be whitelisted by skymapdevs@ and then you need to opt in via a link.
The exception is joining the beta, which just requires joining on Google Play.

| Channel | Whitelist? | Link to join |
|---|---|---|
| Internal | Y | https://play.google.com/apps/internaltest/4699188674449382514 |
| Alpha | Y | https://play.google.com/apps/testing/com.google.android.stardroid |
| Beta | Y | https://play.google.com/apps/testing/com.google.android.stardroid |

Alpha and beta testers should also be able to join via Android by visiting the Play Store at:
https://play.google.com/store/apps/details?id=com.google.android.stardroid
