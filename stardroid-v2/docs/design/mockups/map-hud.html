Bench controls

Q1Which corner?

Top-right — free in both orientations: top-centre belongs to the time-travel player, the left edge to the layer rail (nearly full-height in landscape), and Zone B moves to the bottom-right edge column in landscape.

Decided: top-right Try: time travel toggle

Q2RA format

Astronomy-conventional hours/minutes (18h 38m, shown). Dec, Alt, and the correction stay signed decimal degrees.

Decided: hours/minutes

Q3Is Alt/Az in?

Yes. RA/Dec answers "what am I looking at" for charts; Alt/Az answers it for the actual sky ("how high, which way").

Decided: included

Q4Its own off-switch?

None — the HUD rides the chrome show/hide, so it never costs sky pixels when you're just looking. A Layers-sheet Display toggle only comes if feedback demands one.

Decided: chrome-only, no toggle

Q5Correction row at zero

Strictly hidden when no correction is active — no "aligned" state. The row appearing is itself the signal that something is adjusting the sensors.

Decided: hidden at zero Try: correction toggle + its ✕
